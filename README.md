# PortfolioHUB 🚀

Este repositório centraliza e documenta o desenvolvimento do meu portfólio profissional e acadêmico, desenvolvido durante as disciplinas de Bootcamp do curso de Engenharia de Software. O projeto integra ferramentas do Google Workspace com a infraestrutura do GitHub para criar uma vitrine de carreira segura e automatizada.
